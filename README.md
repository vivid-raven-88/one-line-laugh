## What it does

`main.py` writes one 97-character funny sentence to `/output/entry.txt` —
a single sentence that stands alone:

> My code compiled on the first try, so I spent the rest of the day
> looking for what it was hiding.

The joke turns a rare success into a reason for suspicion: the code
compiled first try, so the rest of the day goes into finding the bug it
must be hiding — an everyday truth every programmer recognises.

## Run it

```sh
python3 main.py
```
